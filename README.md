# Free Blog React Project

This project provide free service for blog sites, with backend, api and customization with an admin system to add posts.

Currently, the project is on building.

## Admin Service ##
The built-in admin service in this repo let you do dome basic things FOR NOW
## Add pages ##
When you enter the Home Page, if you are an admin and your token is valid, you will se a route to add pages,
# In this functionality you can: #
Add and delete many textBox you want
Add Images and delete images to your post
[ IN WORKING ]
Add a more complex text editor options like, bold and italic
Add links and Audio.
## Modify Pages ##
You can modify page title, and the rest of the content of your post
## Delete Pages ##
You can get delete your post whenever you want

## UPCOMING FEATURES ##
Comment, like and favorite sections
